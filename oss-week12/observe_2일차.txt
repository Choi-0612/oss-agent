12주차 스킬 검토 기록 — movie-rank

movie-rank 는 예시 스킬. 남이 만들어 보낸 스킬이라고 생각하고 읽을 것
설치하거나 실행하지 않고 읽기만 함
번호는 검토 기준 번호와 같음. 괄호 안의 "볼 곳"을 열어 보고 답할 것.


1. 전부 읽었나
   이 스킬 폴더에 파일이 몇 개 있나? 이름을 모두 적기
   (볼 곳: VS Code 탐색기에서 폴더를 모두 펼치기)
   답: scripts 폴더에 top3.py, LICENSE 파일, SKILL.md 파일

2. 설명대로만 하나
   이 스킬은 무엇을 하는 스킬인가? 한 줄로.
   top3.py 가 하는 일도 그 설명과 같은가?
   (볼 곳: SKILL.md 맨 위 description, scripts/top3.py)
   답:영화진흥위원회(KOBIS) 일별 박스오피스에서 특정 날짜의 1위부터 3위까지 영화 제목을 알려준다.
   동일하게 동작한다.

3. 바깥으로 보내는 곳
   이 스킬이 내 컴퓨터 밖의 서버에 연결하는 곳이 있나?
   있으면 그 주소와, 무엇을 보내는지 적기
   (볼 곳: Ctrl+Shift+F 로 http 검색. 파일 이름과 줄 번호)
   답:
   주소 https://www.kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json
   보내는 내역 : API_KEY, date

4. 키와 비밀
   키를 코드에 직접 적어 두었나? 키는 어디서 읽어 오나?
   (볼 곳: Ctrl+Shift+F 로 key 검색. 파일 이름과 줄 번호)
   답: 키는 코드에 직접 들어있지 않음. 
   키는 import해서 secret에서 가져와서 읽어 API_KEY로 읽음

5. 지시와 권한
   SKILL.md 에서 Claude 에게 시키는 문장을 옮겨 적고,
   Claude 가 그대로 따르면 어떻게 되는지 한 줄로
   (볼 곳: SKILL.md 의 "지킬 것")
   답:
   스크립트의 출력만 근거로만 답한다.
   자료가 없다는 안내가 나오면 그대로 사용자에게 전한다.
   클로드가 이 내용을 따른다면 결과값이 없을 때, 추론하지 않고 답한다.

6. 라이선스
   라이선스 이름은? 이 스킬을 복사해서 남에게 줘도 되나?
   (볼 곳: LICENSE 첫 줄)
   답: MIT 라이센스, 가능하다
